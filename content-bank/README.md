# بانک محتوای نشاط زندگی

این پوشه بانک محتوای ساخت‌یافته و مستقل از کد اندروید است. فایل قدیمی `content .json` عمداً دست‌نخورده باقی می‌ماند.

## قرارداد داده
هر رکورد این فیلدها را دارد:
- `id`: شناسه یکتا در بانک
- `category_id` و `subcategory_id`: شناسه‌های واقعی Supabase
- `content_type`: نوع محتوایی که همگام‌ساز اندروید می‌شناسد
- `title` و `body`: عنوان و متن اصلی
- `payload`: داده‌های اختصاصی نوع محتوا
- `source_type` و `source_name`: منشأ محتوا
- `is_published`: رکوردهای بانک تا زمان بازبینی و انتشار، false می‌مانند

این فایل‌ها منبع ذخیره‌سازی محتوا هستند؛ ایجاد آن‌ها به‌تنهایی به معنی درج در Supabase یا انتشار برای کاربران نیست.

## هدف بانک اولیه
۱۹ زیرعنوان محتوایی، هرکدام ۱۰۰ مطلب، به‌علاوه ۱۰۰ مطلب تکمیلی برای «تلنگر معنوی امروز» و ۱۰۰ مطلب تکمیلی برای «حال خوب زندگی»: در مجموع ۲۱۰۰ مطلب.

«بازی‌های نشاط‌آور» بنر مستقل بازی‌هاست و در این بانک محتوای متنی شمرده نمی‌شود.

## وضعیت
- [x] کتابخانه مجزای «حال خوب زندگی» (زیرعنوان ۱۶، دسته ۴): ۱۰۰ مطلب پایه
- [ ] ۲۰۰۰ مطلب دیگر: در بسته‌های مستقل و قابل اعتبارسنجی تکمیل می‌شود.

## نکات کیفی
- محتوای خانواده با ساختار انگیزه‌سازی، اقناع اندیشه، تحریک احساس و رفتار‌سازی تولید می‌شود.
- نقل‌قول‌ها، احادیث، آیات و روایت‌های شهدا بدون منبع قابل اتکا به‌عنوان نقل مستند درج نمی‌شوند.
- مطالب شوخی و معما باید پاکیزه و عاری از توهین قومی، مذهبی یا زبان رکیک باشند.
- بانک اولیه نباید باعث حذف یا بازنویسی محتوای موجود شود.
