# بانک محتوای نشاط زندگی

این پوشه بانک محتوای ساخت‌یافته و مستقل از کد اندروید است. فایل قدیمی `content .json` عمداً دست‌نخورده باقی مانده است.

## قرارداد داده
هر رکورد شامل شناسه یکتا، شناسه دسته و زیرعنوان Supabase، نوع محتوا، عنوان، متن، payload و اطلاعات منشأ است. رکوردهای این بانک با `is_published: false` ذخیره می‌شوند؛ بنابراین درج در Supabase به معنی انتشار در اپلیکیشن نیست.

## هدف اولیه
۱۹ زیرعنوان محتوایی × ۱۰۰ مطلب، به‌علاوه ۱۰۰ مطلب تکمیلی برای «تلنگر معنوی امروز» و ۱۰۰ مطلب تکمیلی برای «حال خوب زندگی»: مجموع ۲۱۰۰ مطلب.
«بازی‌های نشاط‌آور» بنر مستقل بازی‌هاست و در بانک محتوای متنی محاسبه نمی‌شود.

## وضعیت بانک
- بسته‌های ذخیره‌شده: ۱۹ بسته × ۱۰۰ رکورد = ۱۹۰۰ رکورد.
- باقی‌مانده: ۲۰۰ مطلب برای دو زیرعنوان «از لب‌های آسمانی» و «گنجینه‌ای از عترت».
- فایل‌های موجود پیش‌نویس‌اند و پیش از انتشار نیازمند بازبینی محتوایی و فنی‌اند.
- مطالب «از لب‌های آسمانی» باید روایت مستند با منبع معتبر باشند؛ از ساختن خاطره یا انتساب نادرست به شهدا خودداری می‌شود.
- مطالب «گنجینه‌ای از عترت» باید متن حدیث، مأخذ دقیق و بررسی انتساب داشته باشند؛ حدیث یا منبع ساختگی درج نمی‌شود.

## اتصال خودکار به Supabase
گردش‌کار GitHub Actions در `.github/workflows/import-content.yml` با هر تغییر فایل JSON داخل `content-bank/` اجرا می‌شود. برای فعال‌سازی:
1. در GitHub وارد Settings مخزن شوید.
2. از Secrets and variables → Actions، یک Repository secret با نام دقیق `SUPABASE_SECRET_KEY` بسازید.
3. مقدار آن را از Supabase Dashboard → Project Settings → API Keys بردارید. فقط Secret key یا کلید محرمانه سمت سرور را قرار دهید؛ هرگز آن را در فایل‌های مخزن، کد اندروید یا پیام گفتگو قرار ندهید.
4. پس از ثبت Secret، در زبانه Actions گردش‌کار «Import content bank to Supabase» را باز و گزینه Run workflow را اجرا کنید تا بسته‌های فعلی نیز انتقال یابند.

اسکریپت `scripts/import-content.mjs` شناسه دسته/زیرعنوان را با Supabase تطبیق می‌دهد، رکورد تکراری را رد می‌کند، گزارش هر نوبت را در `content_import_batches` ثبت می‌کند و همه رکوردها را با `is_published=false` درج می‌کند. انتقال، فقط افزودنی است: رکورد قبلی را حذف یا بازنویسی نمی‌کند. برای اصلاح یک مطلب واردشده، باید نسخه جدید با شناسه جدید ساخته شود.

## نکات کیفی و انتشار
- مقالات خانواده از ساختار انگیزه‌سازی، اقناع اندیشه، تحریک احساس و رفتار‌سازی پیروی می‌کنند.
- لطیفه‌ها باید پاکیزه و عاری از توهین قومی، مذهبی یا زبان رکیک باشند.
- شعر و یادداشت‌های کتاب در این بانک، تألیفی/تأملی‌اند و نقل‌قول مستقیم از شاعر یا کتاب مشخص محسوب نمی‌شوند.
- برخی مدخل‌های هوش‌آزما هنوز صورت معما و پاسخ یکتای نهایی ندارند و باید پیش از انتشار تکمیل شوند.
- هیچ محتوای موجودی حذف یا بازنویسی نشده است.
